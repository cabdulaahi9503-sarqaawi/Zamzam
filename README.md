# Zamzam’s Medical Graduation Celebration

Open `index.html` in a browser. The website is a self-contained, three-page static site:

- `index.html` — Home
- `journey.html` — Her Journey
- `memories.html` — Memories and a tap/click lightbox

All photographs used by the site are stored in `assets/`, so the pages no longer depend on generated-image links. Fonts remain loaded from Google Fonts when an internet connection is available; the site has built-in serif and sans-serif fallbacks.
